# Project memory

Durable facts about this workspace that are worth carrying between sessions:
recurring gotchas, the owner's preferences, and per-target scope notes.

This is a lightweight, project-local store. The Claude Code harness also has its
own global memory system; use this folder for things that belong *with the repo*
and should travel with it.

## Format

One fact per file, `kebab-case-slug.md`, with a short header line. Keep the index
in this README current.

## Index

- [workflow.md](workflow.md) - how writeups get produced in this repo.
- [scope.md](scope.md) - what is in authorized scope, and what is not.
