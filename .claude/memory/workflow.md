# Workflow

Raw work lives in the owner's Notion (scans, screenshots, commands, cracked
creds), usually under `Labs / Penetration Tester - Level Mid / ...`. Writeups in
this repo are reconstructed faithfully from those notes - only steps actually
performed get documented; unfinished phases are marked as planned "next"
sections, never fabricated.

Owner writes notes in Vietnamese; writeup files are kept in English for
consistency. Chat replies to the owner are in Vietnamese.

Scaffold with `scripts/new_writeup.py`, fill against
`templates/writeup-template.md`, then `scripts/build_index.py` to refresh the
README table.
